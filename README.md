One word describing the boss. Not a title, not a complaint, the whole management style in four letters: everything is urgent, everything was due yesterday, and the word itself is the deadline.

> ASAP

## Run it

```sh
python3 main.py
```

It writes the word to `$MAKEFUN_OUTPUT_DIR/entry.txt` (default `/output`) and prints it.
